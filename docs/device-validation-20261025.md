用户通过手机系统共享提示停止共享，确认电脑正常停止；未关闭桌面窗口，再次点击连接并在手机重新授权后，用户确认画面恢复。该结果验证系统停止共享后的恢复路径，不等同于撤销辅助功能控制权限或物理拔线测试。

用户在投屏中拔掉 USB，确认电脑提示连接中断；插回并解锁手机后，在同一窗口重新连接、授权，确认投屏恢复。本次为一次手动拔插样本，不代表所有 USB 接口、线材或重复拔插均已验证。
