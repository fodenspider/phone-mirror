# iQOO Z9 Turbo：采集文件与 Windows 解码验证

日期：2026-10-22（Asia/Shanghai）。本记录只描述一次采集和离线播放，不是实时投屏性能报告。

## 输入

- 用户设备：iQOO Z9 Turbo；系统型号 V2352A。
- ADB 读取：Android 16，API 36。
- 用户报告的编码器：`c2.qti.avc.encoder`。
- 导出文件：231,293 字节；1 条视频配置、134 条编码访问单元。
- 分辨率：576×1280；关键帧 5 个。
- 首末访问单元 PTS 跨度：10.801204 秒。该跨度不能代表最高可达帧率，也不能直接等同于用户授权后的全部采集时长。
- 消息序号连续、时间戳无倒退，配置的 SPS/PPS 长度合法。

## 本地验证

编译环境：Windows、MinGW-w64 GCC 16.1.0、CMake 4.3.3、Release。

| 路径 | 输入帧 | 解码帧 | GPU 表面帧 | CPU 帧 |
|---|---:|---:|---:|---:|
| 默认：MF 解码器绑定 D3D11 设备管理器 | 134 | 134 | 134 | 0 |
| 兼容：不绑定解码设备管理器 | 134 | 134 | 0 | 134 |

两种路径均完成 D3D11 视频处理并生成 576×1280 最后一帧。最后一帧的 RGB 平均绝对差为 [0, 0, 0]，即逐像素一致；这不是对整段所有帧逐像素比较的声明。

检查默认路径的最后一帧可见手机采集 App 界面，内容可读，无明显花屏。隐藏窗口测试完成了按时间戳播放、改变窗口比例、重新打开文件、中途停止和退出，返回码为 0。

## 验证边界

- GPU 表面输出是已观察到的事实；未通过性能计数器进一步证明每个解码步骤都由专用视频引擎执行。
- 未测量持续 CPU/GPU 占用、功耗、温度或实时手机到电脑延迟。
- 软件解码模式仍通过 D3D11 显示，不覆盖没有可用视频处理 GPU 的电脑。
- 未验证无线、音频、遥控、颜色空间的所有组合、GPU 丢失恢复或中途旋转切换流。
- 手机画面、采集文件和解码截图只留在忽略的本地构建目录，未提交到公开仓库；本报告不包含设备序列号。
