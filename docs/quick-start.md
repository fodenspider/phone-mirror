# Phone Mirror 0.5 预览版使用指南

这是 Windows 桌面应用，首次打开后点击“使用指南”。预览版尚未完成正式签名和完整真机验收，不是最终发布版。

1. 安装电脑端。安装包包含电脑程序和配套手机应用，不需要安装开发工具。也可解压便携包后运行 PhoneMirror.exe。
2. 在使用指南的第一步打开官方组件下载页面，下载 Windows Platform-Tools ZIP，不用解压。从“更多 → 导入连接组件”选择该 ZIP。当前版本仅接受经过校验的 37.0.1 官方包，下载版本变化时需要更新程序支持。
3. 用数据线连接手机，按指南打开 USB 调试，在手机确认授权。指南第二步可安装配套手机应用；若旧版签名不同，安装会失败，不会自动卸载或清除数据。
4. 点击“连接手机”，在手机应用内授权 USB 实时投屏并选择共享整个屏幕。等待期间可点击停止。
5. 鼠标控制需要另外开启手机无障碍服务，并在开始共享前勾选本次允许控制。当前实现点击、松开后的滑动和滚轮；仍待真机验收，不支持持续按住、输入法或声音。

“更多 → 画质”提供省资源（最长边 960、最高 24 帧、目标 2 Mbps）、均衡（1280、30 帧、4 Mbps）、清晰（1920、30 帧、8 Mbps）。默认均衡。设置保存在电脑，下次连接时传给配套手机应用，手机在开始共享前显示档位；已有共享不会动态改变，请结束后重新授权。帧率和码率是请求上限/目标，不是性能承诺；不同档位的真实效果仍待设备验收，清晰档不支持时请选择均衡重试。

“更多 → 离线演示”可在没有手机时浏览连接、授权、共享和断线重试说明。页面明确标注模拟状态，演示期间禁止连接、刷新设备和安装手机应用，不提供虚构画面或性能数据。点击停止或退出演示返回。

“更多 → 恢复默认设置”会询问是否重置设置，不删除采集文件、连接组件或手机应用。“版本与下载页面”打开 GitHub Releases，不自动下载或安装；尚未发布正式版本时可从通过检查的 Actions 获取预览构建。

出现问题时查看窗口提示，或从“更多”复制诊断信息。复制内容只包含版本、桌面平台和预定义错误码，不含画面、设备序列号或连接令牌。

连接多台手机时，点击“更多 → 刷新手机列表”，再到“选择手机”中选择目标。该选择同时用于连接和安装手机应用。已选设备断开后，程序不会改连另一台；请重新连接或重新选择。“自动选择”仅在列表中恰好一台手机时可用，列表刷新由你手动触发，不在后台持续扫描。选择仅保存在本次程序运行内。

卸载电脑程序不会卸载手机应用，也不会清理单独导入的连接组件或用户采集文件。组件保存在本机用户目录的 PhoneMirror/components 文件夹，可在确认不再使用后自行删除。

安装器的主要安装与卸载流程已提供中文提示，少数系统异常仍可能显示英文。正式签名、设备选择及画质设置仍在规划中。

“更多 → 检查准备情况”只检查本机组件和安装包；手机连接和权限需连接后确认。兼容解码、窗口大小与引导进度保存在本机用户目录 PhoneMirror/settings.txt，退出后再次打开仍然有效。设置损坏或超出合理范围时使用默认值，不保存设备标识或连接令牌。说明区域支持滚动和键盘阅读。
