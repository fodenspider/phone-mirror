# Phone Mirror 0.4 预览版使用指南

这是 Windows 桌面应用，首次打开后点击“使用指南”。预览版尚未完成正式签名和完整真机验收，不是最终发布版。

1. 安装电脑端。安装包包含电脑程序和配套手机应用，不需要安装开发工具。也可解压便携包后运行 PhoneMirror.exe。
2. 在使用指南的第一步打开官方组件下载页面，下载 Windows Platform-Tools ZIP，不用解压。从“更多 → 导入连接组件”选择该 ZIP。当前版本仅接受经过校验的 37.0.1 官方包，下载版本变化时需要更新程序支持。
3. 用数据线连接手机，按指南打开 USB 调试，在手机确认授权。指南第二步可安装配套手机应用；若旧版签名不同，安装会失败，不会自动卸载或清除数据。
4. 点击“连接手机”，在手机应用内授权 USB 实时投屏并选择共享整个屏幕。等待期间可点击停止。
5. 鼠标控制需要另外开启手机无障碍服务，并在开始共享前勾选本次允许控制。当前实现点击、松开后的滑动和滚轮；仍待真机验收，不支持持续按住、输入法或声音。

出现问题时查看窗口提示，或从“更多”复制诊断信息。复制内容只包含版本、桌面平台和预定义错误码，不含画面、设备序列号或连接令牌。

卸载电脑程序不会卸载手机应用，也不会清理单独导入的连接组件或用户采集文件。组件保存在本机用户目录的 PhoneMirror/components 文件夹，可在确认不再使用后自行删除。

预览安装器目前使用英文安装步骤，应用内指南为中文；安装器中文化、正式签名、设备选择及画质设置仍在规划中。
